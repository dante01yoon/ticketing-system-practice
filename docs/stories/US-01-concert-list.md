# US-01 공연 목록 보기

**사용자로서** 예매할 수 있는 공연 목록을 보고 싶다. **그래서** 볼 공연을 고를 수 있다.

## 인수 조건
**AC-1 목록 조회**
- Given 공연 2개가 등록되어 있다
- When 공연 목록을 요청한다
- Then 두 공연이 모두 공연 ID, 제목, 공연 일시와 함께 반환된다

**AC-2 공연이 없을 때**
- Given 등록된 공연이 없다
- When 공연 목록을 요청한다
- Then 빈 목록이 성공으로 반환된다

**AC-3 인증 불필요**
- Given `X-User-Id` 헤더가 없다
- When 공연 목록을 요청한다
- Then 정상적으로 목록이 반환된다
