# US-09 예매 확정 알림

**예매한 사용자로서** 내 예매가 확정되면 앱 알림함에서 알림을 받고 싶다. **그래서** 결제가 끝났는지 따로 확인하지 않아도 된다.

알림은 늦을 수 있고 전달 과정에서 두 번 갈 수도 있다. 하지만 **예매 결과는 알림과 무관하게 언제나 정확해야 하고**, 알림함에는 확정 한 건당 알림이 한 줄만 있어야 한다.
계약은 `docs/events.md`.

## 인수 조건
**AC-1 확정 1건 → 알림 1건**
- Given u1의 예매 B가 결제 대기다
- When B 성공 콜백이 오고, 릴레이와 notifier가 돈다
- Then u1의 알림함에 B 알림이 정확히 1건 있다. 같은 성공 콜백이 또 와도 1건이다. 실패·늦은 콜백은 알림을 만들지 않는다

**AC-2 Kafka가 잠깐 멈춰도 확정은 성공**
- Given Kafka가 멈춰 있다
- When B 성공 콜백이 온다
- Then 콜백은 지금처럼 성공하고 B는 CONFIRMED, 좌석은 SOLD다. 알림은 아직 없다
- And Kafka가 다시 켜지고 릴레이·notifier가 돌면 B 알림이 1건 생긴다

**AC-3 소비자를 껐다 켜도 이어 받음**
- Given 여러 예매가 확정됐고 notifier가 일부만 처리한 뒤 멈췄다
- When 예매가 더 확정되고 notifier가 다시 켜진다
- Then 확정된 예매마다 알림이 정확히 1건씩 있다(빠짐·중복 없음)

**AC-4 같은 이벤트가 다시 와도 알림은 하나**
- Given B 알림이 이미 있다
- When 같은 B 확정 이벤트가 토픽에 다시 온다
- Then B 알림은 여전히 1건이다
