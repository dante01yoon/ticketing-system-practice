# US-04 모의 결제로 예매 확정

**사용자로서** 홀드한 좌석을 결제해 예매를 확정하고 싶다. **그래서** 좌석이 내 것이 된다.

모의 결제는 실제 결제 연동 없이 항상 성공한다(PRD 열린 질문 3).

## 인수 조건
**AC-1 내 유효한 홀드 확정**
- Given 좌석 A1을 u1이 3분 전에 홀드했다
- When u1이 A1 예매 확정(모의 결제)을 요청한다
- Then 성공하고, A1은 SOLD가 되며, 응답에 예매 ID·좌석·사용자 u1이 있다

**AC-2 만료된 홀드**
- Given 좌석 A1을 u1이 5분 1초 전에 홀드했다
- When u1이 A1 예매 확정을 요청한다
- Then "홀드 만료"로 거절되고 A1은 SOLD가 되지 않는다

**AC-3 남의 홀드**
- Given 좌석 A1을 u1이 1분 전에 홀드했다
- When u2가 A1 예매 확정을 요청한다
- Then "내 홀드 아님"으로 거절되고 A1은 u1의 HELD로 남는다

**AC-4 홀드 없이 확정**
- Given 좌석 A1이 AVAILABLE이다
- When u1이 A1 예매 확정을 요청한다
- Then "홀드 필요"로 거절되고 A1은 AVAILABLE로 남는다

**AC-5 판매된 좌석은 다시 잡을 수 없다**
- Given u1이 A1 예매를 확정해 A1이 SOLD이다
- When u2가 A1 홀드를 요청한다
- Then "이미 판매됨"으로 거절된다

**AC-6 사용자 헤더 없음**
- Given 좌석 A1을 u1이 홀드했다
- When `X-User-Id` 없이 A1 예매 확정을 요청한다
- Then "사용자 식별 필요"로 거절되고 A1은 u1의 HELD로 남는다

**AC-7 한 좌석은 한 번만 팔린다**
- Given 좌석 A1을 u1이 홀드했다
- When u1이 A1 예매 확정을 동시에 두 번 요청한다
- Then 예매는 하나만 만들어지고 A1은 SOLD이다
