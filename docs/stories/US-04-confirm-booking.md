# US-04 예매 확정 요청 (결제 대기 예매 만들기)

**사용자로서** 홀드한 좌석의 결제를 시작하고 싶다. **그래서** 결제가 끝나면 좌석이 내 것이 된다.

결제는 두 단계다(PRD 「결제 흐름」). 이 스토리는 첫 단계인 확정 요청만 다룬다:
확정 요청은 결제 대기(PENDING) 예매를 만들 뿐 좌석을 팔지 않는다. 좌석이 SOLD가 되는 것은 US-05의 성공 콜백이다.
확정 요청에는 멱등 키(`Idempotency-Key` 헤더)가 있어야 한다. 시각은 모두 서버 시각이다.

## 인수 조건
**AC-1 내 유효한 홀드로 확정 요청**
- Given 좌석 A1을 u1이 3분 전에 홀드했다
- When u1이 키 k1로 A1 확정을 요청한다
- Then 성공하고, 응답에 예매 ID·좌석·사용자 u1·상태 결제 대기·결제 마감 시각(홀드 만료 시각)이 있다
- And A1은 아직 SOLD가 아니다(좌석맵에서 HELD)

**AC-2 만료된 홀드 (경계)**
- Given 좌석 A1을 u1이 홀드했다
- When 홀드 후 4분 59초에 u1이 확정을 요청하면 Then 성공한다
- When 홀드 후 5분 정각 또는 5분 1초에 u1이 확정을 요청하면 Then "홀드 만료"로 거절되고 예매가 생기지 않는다

**AC-3 남의 홀드**
- Given 좌석 A1을 u1이 1분 전에 홀드했다
- When u2가 A1 확정을 요청한다
- Then "내 홀드 아님"(권한 없음)으로 거절되고 예매가 생기지 않으며 A1은 u1의 HELD로 남는다

**AC-4 홀드 없이 확정**
- Given 좌석 A1이 AVAILABLE이다
- When u1이 A1 확정을 요청한다
- Then "홀드 필요"로 거절되고 A1은 AVAILABLE로 남는다

**AC-5 판매된 좌석은 다시 잡을 수 없다**
- Given A1이 u1에게 판매됐다(US-05 성공 콜백)
- When u2가 A1 홀드 또는 확정을 요청한다
- Then "이미 판매됨"으로 거절된다

**AC-6 사용자 헤더 없음**
- Given 좌석 A1을 u1이 홀드했다
- When `X-User-Id` 없이 A1 확정을 요청한다
- Then "사용자 식별 필요"로 거절되고 A1은 u1의 HELD로 남는다

**AC-7 한 좌석에는 결제 대기 예매가 하나**
- Given 좌석 A1을 u1이 홀드했다
- When u1이 서로 다른 키로 A1 확정을 동시에 여러 번 요청한다
- Then 예매는 하나만 만들어지고, 모든 성공 응답은 같은 예매 ID를 돌려준다

**AC-8 멱등 키 없음**
- Given 좌석 A1을 u1이 홀드했다
- When u1이 멱등 키 없이 확정을 요청한다
- Then "멱등 키 필요"로 거절되고 예매가 생기지 않는다
- 키가 255자를 넘으면 "멱등 키 형식 오류"로 거절된다(255자는 허용)

**AC-9 같은 키 재요청은 같은 응답**
- Given u1이 키 k1로 A1 확정을 요청해 응답 R을 받았다
- When u1이 같은 키 k1로 같은 요청을 다시 보낸다(동시에 보내거나, 그 사이 콜백·만료로 상태가 바뀐 뒤에 보내도)
- Then 응답 R과 같은 상태 코드·같은 본문을 받고, 예매는 하나뿐이다
- 특히 같은 키 요청 둘이 겹치고, 앞 요청이 만료 직전(4분 59초)에 성공한 뒤 뒤 요청이 만료 시각 이후에 처리돼도 뒤 요청은 "홀드 만료"가 아니라 R을 받는다

**AC-10 같은 키를 다른 좌석에**
- Given u1이 키 k1로 A1 확정을 요청했고 A2도 홀드했다
- When u1이 같은 키 k1로 A2 확정을 요청한다
- Then "멱등 키 재사용"으로 거절되고 A2에 예매가 생기지 않는다
- (키는 사용자별이다: u2가 k1을 쓰는 것은 별개 요청이다)

**AC-11 같은 사람이 다시 확정을 요청하면 기존 예매 (PRD 열린 질문 4)**
- Given u1의 A1 예매가 확정(CONFIRMED)됐다
- When u1이 다른 키로 A1 확정을 다시 요청한다
- Then 새 예매 없이 그 확정 예매를 돌려준다
- (결제 대기 중이고 홀드가 유효할 때도 같다: 다른 키로 다시 요청하면 기존 결제 대기 예매를 돌려준다)

**AC-12 결제 실패 뒤 재시도**
- Given u1의 A1 예매가 실패 콜백으로 FAILED이고 홀드는 아직 유효하다
- When u1이 새 키로 A1 확정을 요청한다
- Then 새 결제 대기 예매가 만들어진다(결제 마감 시각은 처음 홀드의 만료 시각 그대로)
