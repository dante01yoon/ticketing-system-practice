# US-03 좌석 하나를 5분 동안 홀드

**사용자로서** 고른 좌석 하나를 5분 동안 잡아 두고 싶다. **그래서** 결제하는 동안 다른 사람이 가져가지 못한다.

## 인수 조건
**AC-1 빈 좌석 홀드**
- Given 좌석 A1이 AVAILABLE이다
- When 사용자 u1(`X-User-Id: u1`)이 A1 홀드를 요청한다
- Then 성공하고, A1은 u1의 HELD가 되며, 응답에 만료 시각(홀드 시각 + 5분)이 있다

**AC-2 남의 유효한 홀드**
- Given 좌석 A1을 u1이 2분 전에 홀드했다
- When 사용자 u2가 A1 홀드를 요청한다
- Then "이미 홀드됨"으로 거절되고 A1은 여전히 u1의 HELD이다

**AC-3 만료된 홀드는 다시 잡을 수 있다**
- Given 좌석 A1을 u1이 5분 1초 전에 홀드했다
- When 사용자 u2가 A1 홀드를 요청한다
- Then 성공하고, A1은 u2의 HELD가 되며 만료 시각은 지금 + 5분이다

**AC-4 만료 경계**
- Given 좌석 A1을 u1이 4분 59초 전에 홀드했다
- When 사용자 u2가 A1 홀드를 요청한다
- Then "이미 홀드됨"으로 거절된다

**AC-5 판매된 좌석**
- Given 좌석 A1이 SOLD이다
- When 어떤 사용자든 A1 홀드를 요청한다
- Then "이미 판매됨"으로 거절되고 A1은 SOLD로 남는다

**AC-6 사용자 헤더 없음**
- Given 좌석 A1이 AVAILABLE이다
- When `X-User-Id` 없이 A1 홀드를 요청한다
- Then "사용자 식별 필요"로 거절되고 A1은 AVAILABLE로 남는다

**AC-7 없는 좌석**
- Given 좌석 Z9가 존재하지 않는다
- When u1이 Z9 홀드를 요청한다
- Then "좌석 없음"으로 거절된다

**AC-8 동시 홀드**
- Given 좌석 A1이 AVAILABLE이다
- When 서로 다른 사용자 여럿이 A1 홀드를 동시에 요청한다
- Then 정확히 한 요청만 성공하고 나머지는 "이미 홀드됨"으로 거절된다

**AC-9 자기 유효 홀드를 다시 홀드 (PRD 열린 질문 2)**
- Given 좌석 A1을 u1이 2분 전에 홀드했다
- When u1이 A1 홀드를 다시 요청한다
- Then 성공으로 응답하되 기존 홀드를 그대로 돌려준다: 홀드 시각과 만료 시각이 처음 홀드와 같다(만료 시각을 늘리지 않음)
- And 처음 홀드 후 5분이 되면 A1은 만료된다(4분 59초에는 유효, 5분 정각부터 다른 사용자가 홀드 가능)
